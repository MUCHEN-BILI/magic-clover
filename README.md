# 幸运四叶草 · Magic Clover Reborn

给 Minecraft 加一点运气。打草、砍树、挖矿、翻结构箱子都有机会掉四叶草，右键撕开，掉点东西——可能是泥土，也可能是鞘翅。

现在也能在 [Modrinth](https://modrinth.com/mod/magic-clover-reborn) 下载。

## 内容

- **十级幸运草**：普通 → 木头 → 煤炭 → 铜 → 青金石 → 铁 → 黄金 → 钻石 → 绿宝石 → 下界合金，等级越高开出份数越多（1～3 份）、池子越高级
- **模组幸运草**：从你装的所有其它模组里随机抽一件，装 TACZ 时优先给枪械成品
- **生物幸运草**：随机召唤一只原版生物
- **随机幸运草包裹**：开出随机等级的草
- **18 种幸运事件**：矿石雨、钻石雨、附魔书雨、烟花秀、时空跳跃……
  - 「寻宝竞速」：6 份奖励撒在四周，带发光轮廓和光柱，跑过去捡
  - 「命运抉择」：身边立起两个一模一样的箱子，开一个另一个就塌缩；箱子用战利品表，没开之前里面是空的，信息模组偷看不到
- **两档药水**：幸运药剂（20% / 60 秒）、事件药水（50% / 120 秒），后者带附魔光晕
- **幸运口袋**：按 `P` 打开，54 格一页、可翻页、带搜索框，背包满时掉落物自动收纳
- **枯叶幸运草**：打落叶堆掉落，75% 倒霉 / 20% 小赚 / 5% 血赚，惩罚有下限
- **奖池 136 种物品**：低价值物品成组掉落，龙蛋已移除
- **加权奖池**：按稀有度抽取，传说物品约 2%，每档有独占物品
- **种子合成基础草**：4 个相同种子 → 1 棵基础幸运草
- **随机包裹双配方**：3 皮革 + 6 普通草，或 4 小麦 + 2 普通草
- **JEI 掉落图鉴**：每档幸运草一页，列出完整掉落池与概率（JEI 可选依赖）
- **17 个成就**：独立的进度标签页，十级阶梯 + 特殊收集 + 两个挑战级成就
- **中英双语**：物品名、提示、事件名、成就、告示牌全部走语言文件

**草从哪来**：打草 8%、结构箱子 35%、挖对应矿石 2%（钻石/绿宝石/远古残骸 1.5%）、砍原木 0.8%。只有自然生成的方块才掉落，自己放的不算。

## 安装

- Minecraft **1.21.10 ~ 1.21.11**（同一个 jar 通用）
- Fabric Loader **0.20.1+**
- [Fabric API](https://modrinth.com/mod/fabric-api)（必需）
- Java 21

客户端和服务端都要装：掉落判定、事件、口袋数据都在服务端，口袋界面和键位在客户端。

## 配置

首次启动后生成 `config/magicclover.json`，常用项：

| 配置项 | 作用 | 默认 |
|---|---|---|
| `grassDropChance` | 打草掉草概率 | 0.08 |
| `structureCloverChance` | 结构箱子出草概率 | 0.35 |
| `eventChance` | 平时触发事件概率 | 0.02 |
| `eventChanceBuffed` | 喝事件药水后概率 | 0.5 |
| `buffDuration` | 事件药水持续秒数 | 120 |
| `lesserEventChance` | 喝幸运药剂后概率 | 0.2 |
| `lesserBuffDuration` | 幸运药剂持续秒数 | 60 |
| `eventItemMarker` | 参与型事件的发光轮廓与光柱 | true |
| `modCloverTaczChance` | 模组草开出 TACZ 成品的概率 | 0.9 |
| `modItemBlacklist` | 不想被模组草抽到的物品 id | 空 |

改完重启生效。

## 自己构建

```sh
./build.sh build       # 产物在 build/libs/magic-clover-<版本>.jar
```

`build.sh` 里写死了本机的 JDK 和 Gradle 路径，换机器需要改这两行，或者直接用 Gradle：`gradle build`。

发布新版本用 `release.sh`，一条命令走完改版本号、构建、部署、生成 changelog、提交：

```sh
./release.sh 1.6.0 "新增草的合成升级"
./release.sh 1.6.1 "修了口袋排序" --dry-run   # 先看会做什么
```

## 已知问题

- 旧存档里已经生成过的区块不会补草（箱子内容在区块生成时就算好了）
- 事件只有聊天栏提示和屏幕大字，没有 GUI
- 模组草的池子完全取决于你装了什么
- 口袋里没有排序按钮，只有搜索
