幸运四叶草

Magic Clover Reborn

一个给原版生存加点运气的 Fabric 模组。打草、挖矿、探索结构都能捡到幸运草，右键开出一 stack 奖励；背包满了还有会自动收纳的幸运口袋。

Minecraft 1.21.11 Fabric v1.6.0 客户端 + 服务端

1这个模组是干什么的

一句话：把"运气"变成一种可以收集、可以合成、可以开的资源。它不改动原版核心玩法，只是在你日常做事的时候，偶尔掉点幸运草给你。

🌱
到处都能捡到

打草、挖矿、砍树、开结构箱子，都有机会掉出不同等级的幸运草。

🍀
右键就开

右键幸运草立刻开出奖励，等级越高给的东西越好、份数越多。

🎁
合成升级

低级草能用对应材料合成高级草，一条完整的成长链。

👝
口袋自动收纳

背包满了开出的东西不会掉一地，自动存进专属的幸运口袋。

✨
随机大事件

开草有小概率触发矿石雨、钻石雨、烟花秀等 16 种特殊事件。

⚙️
全部可调

所有概率都写在配置文件里，想改多少改多少。

2怎么玩：三步上手

非常简单，不需要学任何新机制。

先弄到一棵草

打草有几率掉普通幸运草；挖矿会掉对应矿物的草；探索村庄、神殿等结构的箱子也能翻到。或者直接合成。

右键打开它

拿着幸运草按右键，就会开出物品并自动进背包。聊天栏会告诉你开出了什么、去了哪里。

背包满了也不怕

装不下的东西自动进幸运口袋，按 P 打开查看。口袋只能取、不能手动放，是纯粹的"溢出仓库"。

小提示：摸一下草的 tooltip，能看到它是几星、会开出几份物品。星星越多越值钱。

合成升级

所有等级草的合成方式都一样：8 个对应材料围一圈，中心放普通幸运草。下界合金草用碎片（不用锭），模组草用 8 棵普通草围一圈 + 中心一个下界合金锭。

想要需要的材料
木头草8 × 原木
青金石草8 × 青金石
铁草8 × 铁锭
下界合金草8 × 下界合金碎片
模组草8 × 普通草 + 中心下界合金锭

4怎么获得幸运草

概率都刻意调得"逛着逛着就能捡到"，不会让人找半天怀疑模组没装好。

途径掉落概率
打草 / 蕨类普通幸运草8%
挖煤 / 铜 / 铁 / 金矿对应等级草2%
挖青金石矿青金石草2.3%
挖钻石 / 绿宝石 / 远古残骸高级草1.5%
砍原木木头草0.8%
开结构箱子按结构等级给草35%
结构里的箱子内容在区块生成那一刻就定好了。想体验 35% 的爆率，去探索新生成的村庄和遗迹；旧存档里已经开过的箱子不会追溯改变。

5幸运口袋：背包满了的救星

这是模组里最实用的小设计。开草的时候如果背包塞不下，东西不会掉在地上让你到处捡，而是自动飞进一个专属口袋。

⌨️
按 P 打开

随时随地按 P 就能翻页查看，最多 54 页，容量非常大。

🔒
只能取不能放

口袋是"溢出仓库"不是背包扩展，手动放东西进去会被拦下来。

🔍
支持搜索

顶部有搜索框，输入名字就能高亮当前页匹配的物品，翻页也支持鼠标滚轮。

6特殊事件：开草还可能触发大场面

开草时有 2% 概率触发一场特殊事件，屏幕中央会弹出大字提示。喝下增益药水后，概率会大幅提升——想看烟火就喝药猛开。

两档药水，前期也能玩

增益药水分两级，高级版带一层附魔光晕（纯装饰，没有实际附魔效果），一眼就能分清。

两个要你动手的事件

大部分事件是「天降奖励」，但这两个得你自己参与：

🏃
寻宝竞速

钻石、绿宝石、附魔书等 6 份奖励撒在四周 8~18 格的地方，得跑过去捡才算你的。

🎰
命运抉择

你身边会立起两个一模一样的箱子，中间一块告示牌写着「稳妥，还是赌博？」。开一个（或砸一个），另一个立刻塌缩消失。稳妥是钻石 ×6；赌博一半概率下界合金 ×3、一半概率腐肉 ×4。

「寻宝竞速」的奖励自带白色发光轮廓（原版「发光」效果，隔着方块也能看见）和头顶光柱，跟着光跑就行；不想要这个指引，把配置里的 eventItemMarker 改成 false。
「命运抉择」的两个箱子用的是战利品表——没打开之前里面是空的，靠 WTHIT / Jade 这类信息模组也偷看不了答案。

还有两个辅助物品： 随机幸运草包裹（开出随机等级的草，可能血赚）和 事件药水（带光晕的高级版）。两种药水都能在创造栏的模组分页里找到。

低级： 朴素无光晕　·　高级：同一张贴图 + 附魔光晕（只做区分，无实际附魔效果）

7成就：17 个可以收集

打开进度界面，会多出一个「幸运四叶草」标签页，里面的树分三条线：

🍀
十级阶梯

从「草」一路到「合金岁月」，拿到每一级草就点亮一个。十级全部拥有过，解锁挑战成就「十全十美」。

🎁
特殊收集

模组草、生物草、随机包裹、两瓶药水，各有对应成就。

🎯
两个挑战

「合金岁月」（拿到下界合金草）和「十全十美」（集齐十种），经验奖励分别是 50 和 200。

成就全部靠「拥有物品」触发，不需要额外操作。所以创造模式直接拿物品也会解锁——它证明不了你是挖出来的，纯粹给收集控一个目标。

8想自己调概率？

安装后会在 config/magicclover.json 生成配置文件，用记事本就能改。常用几项：

配置项作用默认
grassDropChance打草掉普通草的概率0.08（8%）
structureCloverChance结构箱子出草概率0.35（35%）
eventChance平时触发事件概率0.02（2%）
eventChanceBuffed喝药后事件概率0.5（50%）
buffDuration药水持续时间（秒）120
lesserEventChance低级药剂事件概率0.2（20%）
lesserBuffDuration低级药剂持续时间（秒）60
eventItemMarker参与型事件奖励是否显示发光轮廓 + 光柱true
数值写成小数，1.0 就是 100%。比如想把结构箱子改成必出草，就写 "structureCloverChance": 1.0。改完重启游戏生效。

9安装方法

准备环境

安装 Fabric Loader（0.20.1 或更高）和 Fabric API，游戏版本 1.21.10 或 1.21.11，Java 21。

下载模组

最省事的方式是去 Modrinth 项目页 下载，那里有全部历史版本；也可以把 magic-clover-1.6.0.jar 直接放进游戏目录的 mods 文件夹。

启动游戏

进世界就能玩了。创造模式物品栏里有专门的"幸运四叶草"分页，所有物品都在里面。

服务端也要装——掉落判定、事件和口袋数据都跑在服务端；只装客户端的话，多人服务器里看不到任何掉落。
